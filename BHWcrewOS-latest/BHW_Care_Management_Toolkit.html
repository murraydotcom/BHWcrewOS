How to use this tool
Use the Y / N / N/A dropdown in each requirement column — N/A only where an exception is explicitly allowed (e.g., initiating visit not required, no discharge this month). Rows shaded tan are examples; use “Remove example rows” before real audits so they don't skew the dashboard.
