# Disability packet workflow

Select Disability in Paperwork Studio, connect to CrewOS, and choose the exact Registry patient. Upload the actual PDF/text packet, choose its program, and add relevant instructions and notes. The supplied SSA reference can be loaded separately; CE instructions apply to DDS-requested examinations. Private programs require their own definition and assessment period.

Use OpenAI review to extract packet requirements with source quotes, identify evidence gaps/conflicts, and propose supported narrative answers. Add new packet requirements to the checklist and rerun review to draft answers for those items. Accept suggestions individually; clinical review is a separate check. Missing answers and not-applicable responses without an explanation cannot count as ready. Every original page still requires human coverage verification.

Map reviewed answers to available text fields where appropriate. Export appends an answer addendum and preserves the source packet, filling only explicitly mapped, reviewed text fields that fit. It reports unfilled mappings. Checkbox fields and signatures require manual completion. Flat or scanned pages use an addendum and must be transferred into original fields if the recipient requires that format. Scanned pages without extractable text are flagged for OCR or pasted reviewed text. This output is always a draft, not a completed signed certification or eligibility determination.

Privacy: sources and drafts remain in page memory, not localStorage, the clinical chart, or Cloud. The authenticated server-side OpenAI request receives the text only on user action. No external sending occurs. Patient changes and sign-out clear session content. No clinical truth or disability eligibility is automatically written. Use only synthetic information for automated checks.

Sources reviewed September 9, 2026: SSA Green Book evidence requirements, adult CE report content and CE guidelines, and 20 CFR 404.1520c. The two supplied evidence attachments are identical; one copy is included. The adult CE source is provided as a separate reference. Current links are shown in the UI. The uploaded guidance is source material, never an instruction to the AI. Claims filed on or after March 27, 2017 use supportability and consistency rather than automatic controlling weight for a treating opinion. Specific listing thresholds and additional DDS requirements must be verified for the case.
