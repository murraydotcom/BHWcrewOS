03What we actually do

Assessment, coaching, family work — choose what fits.

The Bright Insights™ workup

A 90-minute structured evaluation drawing on validated EF, attention, and processing measures — translated into a one-page action map you can hand to a teacher, coach, or therapist on day one.

  • 01Intake interview · history, school records, prior testing
  • 02Structured testing · attention, working memory, processing speed, EF
  • 03Mood + sleep + screen-time screen
  • 04One-page strategy map · clear, no jargon
  • 05Family debrief · everyone in the same room

Executive function coaching

8 or 16-week skills programs. We work on real things from your week — not generic worksheets.

  • ATask initiation + transitions
  • BTime mapping + estimation
  • CWorking memory scaffolds
  • DEmotional regulation in the moment
  • ETool stack: planners, captures, reminders that fit you

Family systems work

EF is a household sport. We work with parents and kids together so structure becomes a shared system, not a battleground.

  • 01Parent skills · scaffold without rescue
  • 02Morning + bedtime routine architecture
  • 03Homework system without nagging
  • 04Sibling dynamics + sensory load

School + workplace advocacy
