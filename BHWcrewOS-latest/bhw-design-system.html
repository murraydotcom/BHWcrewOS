The idea

Light opal by day, black opal by night

An opal is a quiet stone that holds a whole sky of color inside it. Our light mode is the light opal — light on light: near-white cards floating on a soft pearl field, with gentle flashes of sage green, opal blue, and lavender. Our dark mode is the black opal — that same fire glowing inside dark ironstone, seamed with fine gold. Same stone, two lights. Flip the switch up top to feel it.

For builders

Using the system

One line adopts everything. Link the tokens, load the fonts, and build with the semantic names.

<!-- 1 · link the tokens (once, in <head>) -->
<link rel="stylesheet" href="/assets/bhw-tokens.css">

<!-- 2 · opt in to the base styles -->
<body class="bhw">

/* 3 · build with semantic tokens — light & dark handle themselves */
.appointment-card {
  background: var(--bg-elevated);
  color:      var(--fg);
  border:     1px solid var(--border);
  border-radius: var(--radius-lg);
  padding:    var(--space-6);
  box-shadow: var(--shadow-sm);
}
.appointment-card .cta { background: var(--accent); color: var(--accent-fg); }

Theme follows the patient's device automatically. To pin one, set <html data-theme="light"> or data-theme="dark". A machine-readable copy of every token lives in /assets/bhw-tokens.json for Figma and design tooling.
