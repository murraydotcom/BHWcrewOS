# Shared medication and coding reference

The provider documentation/coding page opens the single protected Health Core library:
https://bhw-health-core-ehr-awknhudemq-uk.a.run.app/terminology-library.html

No catalog is copied into this application. No patient data is passed to the library. This is an explicit reference lookup, not automatic note/diagnosis/claim insertion. Existing coding engines remain documentation and billing rule checks rather than the shared terminology catalog. Google sign-in remains required by Health Core.

Medication and ICD-10-CM lookup use NLM; HCC mapping is explicitly CMS-HCC V28 payment year 2026; CPT remains unavailable until a licensed catalog is configured. Other years/models must not be inferred from this mapping.
